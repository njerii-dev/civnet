# CivNet

CivNet is a community engagement platform designed to improve civic communication, collaboration, and information sharing between community members.

## 🚀 Features

- Responsive and mobile-friendly design
- Community-focused user interface
- Modern component-based architecture
- Fast page loading and optimized performance
- Clean and intuitive user experience

## 🛠️ Technologies Used

- Next.js
- React
- JavaScript
- Tailwind CSS
- Git & GitHub
- Vercel

## 👨‍💻 My Role

I designed and developed the frontend application, implementing responsive layouts, reusable components, and modern UI principles to create an accessible and engaging user experience.
